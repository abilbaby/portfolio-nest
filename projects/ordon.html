ORDON — Organ Transplant Network

A self-initiated full-stack platform designed to solve donor-recipient coordination complexities by implementing secure access layers and logical matching algorithms.

02 / Overview

Project Details

The Core Problem

Organ donor networks frequently struggle with uncoordinated donor registries, waitlist management errors, and complex medical matches. In emergency situations, manual calculations of compatibility metrics can delay crucial organ distributions. The goal of ORDON was to create a centralized database model capable of automating donor-recipient medical matches and managing secure role workflows.

Architectural Solution

ORDON is built upon the Laravel MVC framework, separating routing controls and relational MySQL tables. The database models are structured using strict entity-relationship rules to prevent duplicate patient data. Role-based middleware limits access, ensuring hospital operations, donor registrations, and recipient medical histories remain separate and secure.

Weighted Match Algorithm

The system implements a customized database matching query that evaluates compatibility factors in real time:

  • Blood Compatibility: Restricts queries to strictly compatible AB/O blood type sets.
  • Medical Urgency score: Prioritizes recipient patients flagged with high clinical criticality.
  • Waitlist Duration: Resolves ties by prioritizing patients with longer waitlist durations.
  • Geographic Proximity: Calculates distance vectors between hospital nodes to minimize organ transit times.

Technical Feature Highlights

In addition to the matching query, ORDON implements several advanced features:

  • QR Certificates: Generates verifiable donor registration certificates with encrypted QR verification.
  • Emergency Workflow: One-click hospital node triggers for critical allocation scenarios.
  • Audit Logs: Continuous logging of matching engine adjustments to satisfy security constraints.

Student Reflection & Learnings

Building ORDON taught me how to conceptualize relational database models from scratch. I gained experience in normalising tables, writing composite SQL queries, configuring Laravel middleware security, and using Alpine.js to update matching statistics dynamically without full-page reloads.

ORDON

Organ Donation & Transplant Management System

Project Overview

Laravel 13 PHP 8.3 MySQL Tailwind CSS Alpine.js

Tested and certified by D'Soft Solutions Software Development & Research Centre, Angamaly.

ORDON is a multi-role organ donation and transplant management platform built using Laravel 13 and PHP 8.3. The system coordinates donation workflows between Admin, Hospital, Donor and Recipient users through a structured role-based access control architecture.

System Architecture

The platform implements a multi-role user system where each role — Admin, Hospital, Donor and Recipient — has a distinct permission set and interface. Role-based access control is enforced at the middleware level to ensure secure data separation.

Key Features

  • Designed and developed a multi-role platform for Admin, Hospital, Donor and Recipient users with weighted donor-recipient matching, role-based access control and audit logging.
  • Built emergency organ request workflows, notifications and hospital-managed transplant coordination.
  • Implemented CSV data exports and PDF donation certificates with QR-based public verification.
  • Weighted donor-recipient compatibility matching based on medical criteria.
  • Audit logging for all critical system actions and state changes.

Testing & Certification

The project was completed, tested and certified at D'Soft Solutions Software Development & Research Centre, Angamaly. This real-world testing environment validated the platform's core workflows and data integrity under professional review.
